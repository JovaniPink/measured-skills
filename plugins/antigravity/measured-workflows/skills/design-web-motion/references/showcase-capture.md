# Showcase capture

Identify the intended export, dimensions, assets, rights, and synthetic data label.
A captured presentation may use fixed geometry, but those choices do not become
production defaults. Estimate missing geometry explicitly. Do not invent live users,
activity, performance, or measured outcomes for a convincing demonstration.

Specify frames, transitions, start/rest states, replay, and an accessible static
explanation. Use existing authorized capture tools; no dependency installation,
private uploads, account access, or publication follows from selecting this skill.
Review the result for truthfulness and legibility. A recording proves only what it
shows in that environment, not responsive behavior or runtime performance elsewhere.
