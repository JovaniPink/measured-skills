# Conformance Matrix Reference

Use this reference when source fidelity must be established across several processing stages. NIST test, evaluation, verification, and validation resources in the [NIST AI Resource Center](https://airc.nist.gov/) inform the evidence discipline; this audit contract is independently authored.

## Oracle Contract

Each expected item must identify:

- the pinned source digest and source location;
- the expected semantic value and representation rules;
- whether absence, rejection, or normalization is expected;
- the independent method used to establish the expectation;
- uncertainty or ambiguity that prevents a binary oracle.

An output generated by the system under audit is not an independent oracle for that same system.

## Stage Matrix

| Stage | Required evidence |
| --- | --- |
| Source custody | Identity, digest, size, media type, acquisition authority, and aliases. |
| Decode | Character set, page or object boundaries, decode errors, and raw representation. |
| Parse or extract | Parsed values, source citations, rejected items, and error signals. |
| Normalize | Before and after values, rule, precision, units, and loss assessment. |
| Validate | Rule version, pass or rejection, warnings, and invalid-value handling. |
| Prepare write | Record identity, field mapping, serialization, defaults, and omitted values. |
| Persist | Target test store, receipt, transaction result, constraints, and retry behavior. |
| Read back | Query identity, returned representation, version, and comparison with the write contract. |

## Mutation Families

Include at least factual value changes, missing values, extra values, duplicate records, reordered content, format variation, invalid boundaries, encoding changes, and contradictory sources when relevant. A useful test fails, changes its output, or produces a defined rejection when the source mutation changes the contract.
