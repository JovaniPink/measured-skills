# Workflow-depth scenarios

These 24 fictional cases are prepared, not model evaluations. Each of eight areas
has a useful request, a confusable request and an authority/evidence challenge.
`candidate_route` identifies the route under examination, not a required selection
for every near miss. The output rubric states when a different route fits better.
Review the prompt, starting evidence, expected conclusion, and forbidden claims.
Do not report routing accuracy, model performance, or client acceptance from this
structural fixture. Execution needs a separately authorized client/budget plan.
The existing daily suite, frozen studies and prepared retests are unchanged.
