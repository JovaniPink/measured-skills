# Task discovery and proportionate follow-through

## Scope and evidence

This is an authorized source and website update, not a release or new maintainer
acceptance. Existing candidate work and historical observations remain intact.
The new bytes require their own applicable qualification. The earlier native
loading observations do not qualify these edits. Human usability remains unscored;
an automated browser exercise cannot supply a human chooser result.

## User journey

Describe the work in ordinary language, choose a suggested task, choose its scope
when alternatives exist, fill only known details, inspect the request and copy it.
An explanation stays read-only. A direct repair can select local repair without
a preliminary assessment. Search never grants authority. No account, installation,
model call, or external search service is needed. Unknown queries offer recovery
examples and all tasks, clearly distinguished from matches.

A shared deterministic matcher powers the exported offline and website choosers.
Reviewed phrases and skill aliases outrank partial word overlap. Scope and expected
stopping point stay visible beside copying. Full requests remain inspectable;
installation and stack options are secondary. Fill-ins stay in page memory.

## Design rationale

These primary sources inform design assumptions, not measured outcomes for this
product. Wording and implementation are original.

- [GOV.UK radios](https://design-system.service.gov.uk/components/radios/): use
  an explicit choice for consequential alternatives; do not preselect a scope.
- [NN/g internal search](https://www.nngroup.com/articles/internal-website-search/):
  support task language and synonyms rather than requiring catalog vocabulary.
- [NN/g no-results guidance](https://www.nngroup.com/articles/search-no-results-serp/):
  acknowledge no match and give a clear recovery path.
- [NN/g progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/):
  subordinate optional configuration, while retaining the action boundary.
- [WCAG status messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html):
  expose actual clipboard results without moving focus on success.
- [WCAG reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) and
  [keyboard](https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html): verify
  small-width controls, visible focus and a complete keyboard path.

## Balanced completion

Six failure-mode pairs remain the bounded follow-through suite. Added proportion
checks cover excess work too: do not demand redundant approval, spawn unnecessary
workers, expand into adjacent repairs, or add verification without an unmet
requirement or changed relevant input. Once the authorized outcome is satisfied,
stop. Automated feedback never supplies a pending human decision. A pause or
genuine unavailable prerequisite remains a legitimate stopping point.

Deterministic tests establish export consistency and scenario contracts only.
Record client versions, models, loaded guidance, actual outcomes and limitations
when new native trials are authorized and exercised. Ten ordinary-task observations
remain prospective; do not invent savings, parity or statistical significance.
