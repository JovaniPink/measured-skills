# October 5 source review

All 27 primary sources whose fingerprints changed since their last review now have a current-content decision. Every one still supports the canonical instructions that cite it, so no skill text changes. Twenty-four reviewed fingerprints were updated. Three OWASP fingerprints remain held because repeated requests returned different bytes, as in the [September 30 review](source-review-2026-09-30-semantic.md). The global review date in `catalog/upstream-pins.json` advances to 2026-10-05.

The [initial freshness receipt](source-review-2026-10-05.json) records all 55 pinned URLs at source revision `60a6b3b`: 28 markers matched and 27 had changed, with none unavailable. The [decision ledger](source-review-2026-10-05-semantic.json) keeps the expected and observed markers, the resampled markers, body hashes, affected skills, and each finding. Response bodies were not retained.

## Method

- Each changed URL was fetched twice and its visible text was read against the skills that cite it, found through `provenance/catalog.json` and `catalog/upstream-reviews.json`.
- Each marker was then fetched three more times with the pinned marker kind. A source was repinned only when every fetch agreed.
- The old Swift documentation URL is a redirect. Its destination is a client-rendered application, so the review read the destination's own documentation data (`/latest/data/documentation.json`) rather than the raw HTML shell.
- Three Next.js and React sources pinned for the 0.18.0 owned workflows had no review record. They now have one.
- Unchanged markers are byte-identical to the content they were reviewed against, so their earlier decisions stand.

## Post-review readback

The closing online check matched 52 of 55 fingerprints. The three held OWASP pages still differ, so the online freshness gate keeps failing for those URLs only. The OWASP agentic initiative page matched three resamples and then changed on the closing readback, so it is held too.

## What this does not establish

This review checks that current primary content still supports the bounded instructions. It does not reconstruct what changed upstream, qualify any skill behavior, or authorize release, tagging, or promotion.
